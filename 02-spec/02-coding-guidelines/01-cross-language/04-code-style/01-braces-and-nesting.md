# Braces and Nesting

## Rules
1. **Always Use Braces:** Single-line if statements without braces are prohibited in languages with block braces.
2. **Max Nesting Depth:** Maximum nesting depth is 2-3 levels. If logic requires deeper nesting, extract helper functions.
3. **Mandatory Vertical Blank Lines:**
   - Blank line before `if` statements.
   - Blank line after closing `}`.
   - Blank line before `return` statements.
   - Blank lines around multiline declarations.
