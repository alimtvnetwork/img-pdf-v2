# Boolean Principles: Guards and Extraction

## Rules
1. **Strict Boolean Naming:** Use `is_*` and `has_*` prefix ONLY.
   - Allowed: `is_valid`, `has_header`, `is_empty`, `has_children`.
   - Banned: `can_*`, `should_*`, `was_*`, `will_*`, `did_*`, `allow_*`, `check_*`.
2. **Positive Framing:** Never use negative boolean names.
