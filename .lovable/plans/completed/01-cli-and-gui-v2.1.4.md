# Completed Milestone: CLI & GUI v2.1.4

**Shipped Version:** v2.1.4
**Date:** 2026-05-25

## Accomplishments
- Mixed-input merge engine supporting JPG, PNG, WEBP, BMP, TIFF, PDF, HTML, and Word (DOCX).
- Pencil-sketch look for images with default set to `subtle`.
- Windows Explorer context menu with grouped submenus (`PDF`, `Image`, `UI`).
- Batching runner (`jpg2pdf-selected-runner.cmd`) with hidden `.vbs` queue launcher for Explorer selection verbs.
- Cross-platform Tkinter GUI (`jpg2pdf-gui.exe` / `jpg2pdf.py --gui`) supporting drag-and-drop, options panel, and queue management.
- One-liner installers (`install.ps1` and `install.sh`) with release -> main -> Python source fallbacks.
